# 🌲 Forest

Este é um projeto desenvolvido a partir do curso de **Tailwind CSS** da **Origamid**. O objetivo principal foi construir um site responsivo de hospedagem e experiências em meio à natureza, explorando classes utilitárias, layouts com Flexbox e CSS Grid, personalização de estilos e animações. Nesta implementação, a interface foi organizada em componentes com **React**.

> **Nota:** Este é um sistema fictício criado exclusivamente para fins didáticos e para aprimorar minhas habilidades no desenvolvimento de interfaces front-end com Tailwind CSS.

---

## 🚀 Tecnologias Utilizadas

O projeto foi desenvolvido com foco em estilização utilitária, responsividade e componentização:

- **Tailwind CSS**
- **React**
- **JavaScript (ES6+)**
- **HTML5 e JSX**
- **CSS3**
- **Vite**

---

## ⚙️ Funcionalidades

- 🏡 Apresentação das cabines e acomodações
- 📅 Exibição de oportunidades fictícias de reserva
- 🛶 Galeria de aventuras e atividades ao ar livre
- 🌅 Apresentação das atividades ao longo do dia
- 📱 Interface responsiva com menu mobile
- 🧭 Navegação entre as seções com rolagem suave
- ✨ Animações de entrada e efeitos ao passar o mouse
- 📝 Formulário de contato demonstrativo com validação nativa, sem envio de mensagens
- 🤝 Exibição de marcas parceiras e informações de contato

---

## 📚 Conceitos Praticados

Este projeto foi desenvolvido com o objetivo de consolidar conhecimentos sobre Tailwind CSS e construção de interfaces com React, incluindo:

- Estilização com classes utilitárias
- Layouts com Flexbox e CSS Grid
- Responsividade com breakpoints
- Personalização de cores e animações com `@theme`
- Criação de utilitários com `@utility`
- Seletores e valores arbitrários no Tailwind CSS
- Estados de interação com `hover`, `focus-visible` e `group-hover`
- Transições e animações com `@keyframes`
- Componentização e reutilização de elementos da interface
- Hooks `useState` e `useEffect`
- Criação de um Hook customizado para media queries
- Renderização condicional e controle do menu mobile
- Validação nativa de formulários
- Organização de componentes, estilos e recursos visuais

---

## 🎯 Objetivos do Projeto

Além de colocar em prática a proposta do curso de **Tailwind CSS da Origamid**, este projeto teve como objetivo aprofundar o uso de classes utilitárias para criar layouts responsivos e manter uma identidade visual consistente. A implementação com React também permitiu exercitar a organização da interface em componentes reutilizáveis e o controle de interações com Hooks.

---

## 🎨 Design e Identidade Visual

O projeto segue a proposta visual apresentada no curso da **Origamid**, com uma estética inspirada na natureza. A paleta combina tons de verde e fundos escuros com fotografias de paisagens, acomodações e atividades ao ar livre.

Os títulos em tipografia serifada, os cantos arredondados e as animações sutis reforçam a sensação de tranquilidade, enquanto o layout responsivo adapta o conteúdo a diferentes tamanhos de tela.
